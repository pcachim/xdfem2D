    Installation¶

    xdfem2D comes in two parts, and you install the one you need:

    • The application, with the window, for macOS, Windows and Linux. It is a ready-to-run program: you do not need Python.
    • The engine, the calculation library for Python, for scripts and other programs: Scripting with the engine.

    The application¶

    1. Download the file for your system from the Releases page of the project. Each release has these files (<version> is the number of the release):

      System File What it is
      macOS xdfem2D-<version>-macOS.dmg a disk image with the application, for Macs with Apple silicon (M1 or later); there is no version for Intel Macs
      Windows xdfem2D-<version>-windows.exe an installer (NSIS)
      Linux xdfem2D_<version>_<arch>.deb a package for Debian and Ubuntu (<arch> is amd64 or arm64)
      Linux xdfem2d-<version>-linux.zip the application in a folder, for any distribution: unpack and run

    2. Install it:

      System What to do Where it ends up
      macOS Open the .dmg and drag xdfem2D onto the Applications folder /Applications/xdfem2D.app
      Windows Run the installer. It asks for administrator permission, installs the program, puts a shortcut on the desktop and lists it under Apps so that it can be uninstalled C:\Program Files\xdfem2D\xdfem2D.exe
      Linux, .deb sudo apt install ./xdfem2D_<version>_<arch>.deb: it installs the program, a command and an entry in the applications menu /opt/xdfem2D, and the command xdfem2D (/usr/bin/xdfem2D)
      Linux, .zip Unzip it anywhere and run xdfem2D from the folder; there is nothing to install the folder you unzipped it to

    3. Start it. The first time, xdfem2D shows a notice that you must accept. It is the same notice the MCP server needs accepted before it will start.

    If macOS stops it

    The application carries an ad-hoc signature, not one from an Apple developer certificate, so macOS may ask you to confirm the first time: right-click the app ▸ Open, or allow it in System Settings ▸ Privacy & Security. It happens once.

    Opening files. A .x2d file opens in xdfem2D when you double-click it. A solved example to try is examples/example_2level_2bay_full.x2d, in the repository.

    How long a version works. Each version of the application is valid until a date: Help ▸ Expiration Date shows it. When it passes, download the current version.

    Where it keeps its settings. In the folder .xdfem2d of your home folder (~/.xdfem2d): the preferences, the recent files and the history of the Assistant. Deleting it resets the application to its defaults. Your models are the .x2d files you saved.

    Optional tools¶

    Nothing below is needed to model, analyse and design. Each one adds something:

    Tool Adds See
    Ollama the Assistant, with a model that runs on your computer The AI Assistant
    Claude Code, Ollama's cloud models, OpenCode the Agent tab The Agent tab
    pandoc editable equations in the Word design reports (without it they are pictures) Design reports

    Preferences ▸ Dependencies shows which of these are installed, what each unlocks, and the command to install it on your system.

    Updating and uninstalling¶

    To update, install the new version over the old one; your preferences and models are untouched. To uninstall: on macOS, drag the application to the bin; on Windows, uninstall it from Settings ▸ Apps; on Linux, sudo apt remove xdfem2d for the .deb, or delete the folder for the .zip. Delete ~/.xdfem2d as well if you also want the settings gone.

    The engine for Python¶

    pip install xdfem2d

    It needs Python 3.12 or newer, and installs numpy, scipy and eurocodepy with it. It has no interface, and needs none. A first script, the conventions and the reference of every call are on Scripting with the engine. The engine is free software under the LGPLv3; the application is freeware, under its own terms (Licenses & Disclaimer).
