    Geometry objects (parametric)¶

    Instead of placing every node and element by hand, you can define the structure with parametric geometry objects that the program discretises into concrete nodes and elements at solve time. The editable model is left untouched; the analysis runs on the compiled mesh (Analysis ▸ Generate mesh, F6, builds it earlier so you can inspect it).

    Objects are node-driven: each one refers to real nodes of the model, and stores no coordinates of its own, so moving a node reshapes every object that uses it.

    Object Becomes Defined by Meshing control
    Segment bar elements its two end nodes Divisions (equal parts), or Max chord
    Arc bar elements (straight chords) a start node, a node on the arc and an end node (in the GUI you click the three points; the engine also accepts centre, radius and angles) Divisions (8 by default), or Max chord
    Multisegment bar elements a chain of nodes, open or closed Divisions (one count for all, or one per span), or Max chord
    Rectangle triangle or quad mesh two opposite corner nodes (an axis-aligned rectangle) Target size [m]: the edge length wanted
    Polygon triangle or quad mesh a closed polygon of nodes Target size [m]

    Create objects from Structure ▸ Objects (Add segment…, arc…, multisegment…, rectangle…, polygon…) and edit them in Manage objects…. A curve also carries its own loads, in the Loads tab of its editor.

    How a surface is meshed¶

    A surface has two meshers, and the outline decides which one runs.

    • Structured — for a convex outline with four vertices: every rectangle, and a polygon that is a convex quadrilateral. A mapped grid, with the diagonals alternating by quadrant, so the mesh is symmetric about both mid-planes. With a quad section (Mesh as: Quads) each well-shaped cell is kept as one quad; a cell that would be poorly shaped is split into two triangles, so the result can be a mix of both.
    • Delaunay — for every other outline, in triangles only. The boundary is refined to the target size, an interior grid of points is added, nodes that already exist are kept, and triangles whose centroid falls outside the polygon are discarded. It uses SciPy's Delaunay, with a built-in implementation if SciPy is missing. The triangulation is not constrained: a strongly re-entrant outline (a deep notch) can be bridged by a triangle, so look at the generated mesh of a concave polygon before relying on it.

    Quads therefore need a convex outline with four vertices. For any other polygon (a circular sector, a ring, an L) the editor switches Quads off, says why under the box, and meshes it as triangles. Model check reports two cases that are not errors but are worth reading:

    • Lost quad elements: the object asked for a quad section and got no quad at all. The fix is Mesh as: Triangles.
    • Mixed formulation: the object got some quads and some fallback triangles. They are displacement-compatible, but the moments or stresses recovered on the two kinds of element are not directly comparable across their boundary.

    Where objects meet¶

    When the model is analysed, bars that coincide are merged, and a node that lies on the span of another object splits that span there (a T-junction), so the parts act together. Crossings are different: two objects that cross are only joined at the crossing when one of them has Intersect with crossing members on. It is off by default; a crossing connects if either of the two objects has it on.

    The edges of a meshed surface¶

    Supports and springs assigned to the corner nodes of a meshed edge carry to the nodes the mesher creates along that edge. This is how you fix a whole wall base with two assignments instead of forty. The rectangle's editor controls it:

    Control Options
    Edge supports Common restraints (min) (the default): the degrees of freedom restrained at both corners. Only if identical: only when both corners restrain the same ones. None.
    Edge springs Linear variation (the default): the corner springs kx, ky, kt interpolated along the edge. None.
    Per-edge override A support for each of the four edges (bottom, right, top, left), instead of deriving it from the corners. Set one and all four must be set.

    The per-edge override exists because the corner rule cannot express a pattern such as clamped / simply supported / clamped / simply supported around a slab: a corner shared by a clamped edge and a simple one would clamp both.

    Turning an object into ordinary elements¶

    To change the result by hand, bake the object first: Edit ▸ Line to bar turns a segment, arc or multisegment into its bar elements, and Edit ▸ Surface to mesh turns a rectangle or polygon into its triangles and/or quads. The object is deleted and the elements are yours to edit one by one.
