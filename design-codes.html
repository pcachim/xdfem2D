    Design codes and preferences¶

    Three things set up a design before it runs: the code edition of each material, the parameters of each code, and the combinations to design for. All of them are in the Design menu.

    Code editions¶

    Material Code Editions
    Concrete EN 1992-1-1 (EC2) 2004, 2023
    Steel EN 1993-1-1 (EC3) 2005
    Timber EN 1995-1-1 (EC5) 2004, 2025

    The formulae are those of eurocodepy, a required dependency of xdfem2D; the application gathers the actions, calls the checks and shows the results. The report of each check names the clause it applies (see Design reports).

    There are two places to choose an edition:

    • File ▸ Preferences ▸ Design sets the edition given to new models, one for each material.
    • Design ▸ Code preferences sets the edition, and every other parameter below, for the open model.

    The code that a design was run with is stored inside the .x2d with its results. When you reopen a file that was already designed, its stored code takes precedence over the preference default, so a model keeps the code it was designed with. Changing any code preference discards the design results of the open model (they were computed under the old values); so does a new analysis.

    What the 2023 edition changes, and what it does not

    EN 1992-1-1:2023 changes the design of bars (the concrete strength fcd = ηcc·ktc·fck/γc, the shear of §8.2, the torsion of §8.3 and the combined shear and torsion), of membranes (Annex G.3), of slabs (Annex G.4) and of punching (§8.4). The crack width (EN 1992-1-1:2004 §7.3.4) and the anchorage and lap lengths keep the 2004 rules, and for columns the slenderness, second-order and N–M rules are still those of 2004; only fcd is the 2023 one. See Concrete: members, Concrete: slabs and walls and Concrete: punching.

    Code preferences¶

    Design ▸ Code preferences has one tab per code: EC2 · Concrete, EC3 · Steel, EC5 · Timber and General. These are all its parameters, with their defaults. A scripted model sets the same keys in the prefs of the design functions (see Python API: results and design).

    EC2: common¶

    Parameter Default What it is
    ec2_edition 2004 EN 1992-1-1:2004 or :2023
    gamma_c 1.5 partial factor of concrete
    alpha_cc 1.0 long-term factor αcc (2004). In 2023, ηcc·ktc is used instead
    gamma_s 1.15 partial factor of reinforcement

    EC2: serviceability (crack width)¶

    Parameter Default What it is
    wk_max 0.3 mm crack-width limit
    sls_combo Quasi-permanent the SLS combination: Quasi-permanent, Frequent or Characteristic

    EC2: beam bars (areas to bars)¶

    How the required areas of a beam become bars. See Concrete: members.

    Parameter Default What it is
    beam_diameters 10, 12, 16, 20, 25, 32 mm bar diameters available
    beam_stirrup_mm 8 mm stirrup diameter assumed for the cover
    beam_max_layers 2 maximum layers per face
    beam_max_diameters 2 maximum distinct diameters per face of a beam
    beam_n_through 2 continuous (through) bars per face
    beam_symmetry rule bar symmetry: rule (odd counts of 3 or more allowed, symmetric curtailment), even (even counts only) or none
    beam_zone_mode cutoff zones along each span: cutoff (at the steps of the envelope) or fixed (fractions of the span)
    beam_cutoff_levels 3 steps of the envelope, in cutoff mode
    beam_min_zone_length 0.5 m shorter zones are merged
    beam_support_bottom_ratio 0.25 bottom steel that reaches the supports, as a fraction of the maximum span steel (EC2 9.2.1.4)
    beam_shift_d 0 shift of the envelope, in effective depths (EC2 9.2.1.3); 0 is off
    beam_top_min_ratio 0 As,min imposed on the top face, as a fraction of As,min
    beam_stirrup_legs 2 stirrup legs
    beam_stirrup_diameters 6, 8, 10, 12 mm stirrup diameters available
    beam_stirrup_spacings 75 … 300 mm stirrup spacings available
    beam_anchorage_shape straight bar ends: straight or bent (hooks)
    beam_lap_percentage 50 % lapped bars in a section (ρ1)
    beam_bar_length 12 m commercial bar length

    EC2:2023: punching¶

    Parameter Default What it is
    gamma_v 1.4 partial factor of punching
    eta_sys 1.5 system factor of punching
    dmax 20 mm maximum aggregate size

    EC2:2023: concrete strength and membranes¶

    Parameter Default What it is
    ec2_k_tc 1.0 ktc: 1.00 for a concrete loaded three months or more after casting, 0.85 otherwise
    ec2_nu_mode simple ν of membranes and of the sandwich layers (Annex G): simple is 0.4 (Eq. G.8), strain is from the strains (Eq. G.9)
    ec2_strut_model annex_f the concrete strut of membranes and, in 2004, of Wood–Armer slabs: annex_f is ν·fcd with ν = 0.6(1 − fck/250), 6.109 is EN 1992-2 §6.109 (with the angle to the elastic direction)
    ec2_slab_method auto slabs, Annex G.4: auto uses Tables G.2/G.3 and the sandwich model where they do not apply, optimum only the tables, sandwich only the sandwich model

    EC3: steel¶

    Parameter Default What it is
    ec3_edition 2005 EN 1993-1-1:2005
    gamma_M0 1.0 cross-sections
    gamma_M1 1.0 member buckling
    gamma_M2 1.25 fracture and joints
    steel_class4_effective on use the effective properties of Class 4 sections
    steel_ltb_rolled on the rolled and welded sections method for lateral-torsional buckling (§6.3.2.3)
    steel_interaction_method B interaction factors kij (§6.3.3): Annex B (method 2) or Annex A (method 1)
    steel_ky, steel_kz, steel_klt 1.0 default buckling-length factors, per axis and for lateral-torsional buckling
    steel_E, steel_G 210000, 81000 MPa moduli
    steel_cmy, steel_cmz, steel_cmlt 0.9 default equivalent-moment factors
    steel_c1 1.0 default LTB moment factor

    EC5: timber¶

    Parameter Default What it is
    ec5_edition 2004 EN 1995-1-1:2004 or :2025
    timber_gammaM_solid 1.3 γM of solid timber (C, D)
    timber_gammaM_glulam 1.25 γM of glued laminated timber (GL)
    timber_gammaM_lvl 1.2 γM of LVL
    timber_gammaM_clt 1.25 γM of CLT
    timber_gammaM_panels 1.2 γM of wood panels (plywood, OSB)
    timber_taper_step_warn 0.1 warn when the depth of a tapered beam jumps by more than this between bars

    Buckling: free-end members¶

    Parameter Default What it is
    cantilever_auto on apply an automatic K to a member with a free end
    cantilever_k 2.0 that K, for K_y and K_z

    See Buckling lengths.

    Other¶

    A national annex is chosen in a script with the ec2_annex preference (a country code; none by default). It is not in the dialog. The strengths fck, fyk and fy are not preferences: they come from the material of each section (see Materials and sections for design).

    Design combinations¶

    Design ▸ Design combinations chooses which load combinations are checked, in two tabs: ULS (all the designs) and SLS (the crack width). Every combination of the model is listed in both, and a combination can be in only one of them: ticking it in one tab clears it in the other. When nothing has been chosen yet, the ids that start with ULS or ELU are ticked for ULS and those that start with SLS or ELS for SLS.

    Generate the EN 1990 combinations with Analysis ▸ Auto Comb. (EN1990)… (Ctrl+Shift+C) (they take the action type of each load case, and the ψ factors, which have defaults from eurocodepy), or define your own on the Combinations sub-tab. See Analysis.
