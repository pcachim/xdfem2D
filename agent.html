    The Agent tab¶

    The Agent tab is the second tab of the AI panel (View ▸ AI panel, or F10; View ▸ Agent tab opens it directly). In it a program that works by itself, Claude Code, one of Ollama's cloud models or OpenCode, builds, changes, analyses and designs on the model you have open, with the same tools as the MCP server. You watch the drawing change as it goes, you can edit between its steps, and each of its changes is one step of Undo.

    It is not the Assistant. The Assistant answers one request at a time, usually with a small model that runs on your computer. The Agent takes a request that needs several steps ("a three-storey frame, designed, with a report") and does the steps itself, with a capable model that is usually in the cloud.

    Using it¶

    1. Choose the agent and the model.
    2. Write what you want and press Cmd+Enter (Ctrl+Enter elsewhere); Enter is a new line.
    3. The first time, the window tells you where your model goes (see below). Nothing is turned on until you send a message.
    4. Watch the drawing and the list of steps in the conversation. Stop interrupts it; New conversation starts afresh.

    The controls¶
    Agent The program that does the work: Claude Code, Ollama (cloud) or OpenCode. A name followed by (not tried) has not been tested for real.
    Model The model it uses: for Claude Code its own default, Sonnet, Opus or Haiku; for Ollama (cloud) the cloud models your Ollama has. Refresh reads the list again.
    Options What an agent that connects from outside needs: for Claude Code the connection, the token, the environment and the registration (see below). Greyed out for Ollama (cloud), which has nothing to set.
    The box and Send Write the request; Cmd+Enter sends. While the agent works, Send becomes Stop.
    New conversation Clears the conversation and what the agent remembers of it. The tab does it by itself when you create or open another model, because its memory of the old one would mislead it.
    ⓘ Opens this page in the application, with no internet needed.
    The line at the bottom Where the connection stands.

    The agents¶

    Claude Code is run without a terminal (claude -p), given the server of the window in the request itself, so nothing has to be registered for the tab to work. It is closed in on the tools of the application: it has no shell and it cannot edit files. Options holds the connection: turn the server on or off, see the token, set the environment it runs in (KEY=VALUE lines, for example ANTHROPIC_BASE_URL=http://localhost:11434 to use a model that runs on this computer), and Register with the agent, which runs claude mcp add for you so that Claude Code can also use the server outside the window.

    OpenCode (opencode.ai) is a program like Claude Code that talks to many providers: its own free models, OpenAI, and a model that runs on this computer through Ollama. Install it and choose a model in it once; the Model list shows the ones it offers. It is run without a terminal and given the server of the window for that run only; everything else it could do (a shell, editing files) is refused. Where your model goes depends on the model you choose: a local one (ollama/…) stays on this computer, the others are sent to their provider, and the tab says which. OpenCode's own free models cost nothing, but each has the terms of its provider: some keep nothing and do not train on what you send, one keeps it for 30 days, some may use it to improve the model, and the Nemotron ones are for trial use only, not for personal or confidential data. The list notes it beside each name, the notice says it again, and the terms can change: see OpenCode's page. Do not use a free model on a confidential project. With Default in the model list OpenCode picks the model itself (its configuration, else the last one you used), so the tab cannot say where your model goes: choose a model to know.

    Ollama (cloud) runs inside the application, for Ollama's cloud models only (gemma4:cloud, gpt-oss:120b-cloud …). It needs Ollama installed and signed in (ollama signin), and nothing else: no server, no token, no registration. Nothing runs on this computer, but every step is a request to Ollama's cloud and counts against your Ollama usage; the tab says how many calls a message took. If the quota is used up, or you are not signed in, it says so in those words. It keeps the last 40 messages of the conversation.

    Where your model goes¶

    Claude Code sends what you write and your model (nodes, loads, results) to Anthropic to answer, as it does in a terminal. Ollama (cloud) sends them to Ollama (ollama.com). The window says so once for each agent (with Don't show this again). With a model that runs on this computer it says that it stays here; small models often fail on requests of several steps. Do not use an agent on a project you may not share.

    What the agent can do in the window¶

    • Build and change the model with the command language, including copying, arrays, rotations and mirrors, and the mass, modal, response-spectrum and P-Delta cases.
    • Analyse and design, and read the results; the window is locked on them as after a Run, and the design shows in the design views.
    • Show things: a view or a diagram (moment of the combination C1), the layers, the colours of the results, the grid, the zoom. A figure written to a file is a different request: it needs a path.
    • Select: a select marks bars and nodes in the drawing, so you see what it means.
    • Save and open files, lock the model so that nothing changes it, undo.

    The tools are listed in The MCP server.

    What to know¶

    • Turns, not a race. Each tool the agent calls reads the model as the window has it at that moment and writes its change back at the end. If you edit between two calls it sees it in the next one. If you edit during one, that call writes nothing and says so, and the agent repeats it from what it reads again.
    • Long calls keep the model still. While an analysis, a design or an export runs, the status bar shows Agent: working (...) and editing is switched off, as when the Variants panel is open. A short call does not take the model away.
    • Undo is yours. Each call that changes the model is one step of Edit ▸ Undo, together with your own. The status bar says what it did (Agent: +2 nodes, +1 bar).
    • Editing a solved model drops its results, whoever edits.
    • Selection. select adds to what is selected (as in a CAD program); select only replaces it, deselect takes from it, select none clears it and select previous goes back to the previous selection of the Selection menu. An action that uses the selection (move, divide, delete …) leaves nothing selected; select previous brings it back.
    • Files. What the agent saves goes to the folder of the open model, or to the default file location of Preferences when no model is open; nobody chooses it, it follows the model you open, and a path outside it is refused. A file it saves or opens becomes the one the window has open and joins File ▸ Open recent, as when you do it.
    • Safety. The server of the tab listens on this computer only (127.0.0.1) and answers only a client that sends the token. It turns off when you close the window, and it is never on unless you started it by sending a message.
    • Not shared. The zoom, the scenes and the variant you are looking at are yours; the agent works on the base model.

    If something does not work¶

    What you see Why
    Claude Code was not found on this computer (or OpenCode) It is not installed, or not on the path of the application. Install it, or start the application from a terminal where claude (or opencode) works.
    Sign in (Ollama cloud) Run ollama signin in a terminal.
    Limit reached (Ollama cloud) The free usage of the period is used up: wait, or use another agent.
    Claude Code says it cannot connect to xdfem2d-window A registration made earlier, in the folder you were in, has another port and wins there: run claude mcp remove xdfem2d-window -s local in that folder (claude mcp list shows both). The tab's own conversation does not use registrations.
    The agent asks for a path A figure or an export written to a file needs one; to see a view, ask it to show it.
    A model of Ollama is not in the list Only the cloud models are offered; Refresh reads the list again.
