    Getting Started¶

    This walkthrough builds a portal frame, loads it, analyses it, reads the results and designs it, in about fifteen minutes. At each step it says what you should see, so that you can tell whether you did it right. The frame is a reinforced-concrete portal, 6 m wide and 4 m high, with fixed bases and 20 kN/m of live load on the beam.

    The window and its parts are on The Interface; open it beside this page if you want to find a button.

    Plane or plate

    Every model is either plane (frames and walls) or plate (slabs and grillages), chosen once in New model. A template chooses it for you. This walkthrough is a plane model; see Domains for the choice.

    1. Start from a template¶

    Choose File ▸ New from Template… (Ctrl+T). Set Category to Beams & Frames and Type to Portal, enter a span of 6 and a height of 4, leave the rest as it is (the beam is 0.30 × 0.50 m, the columns 0.50 × 0.30 m, concrete C30/37), and press OK.

    You should see the frame drawn and fitted to the canvas, with a fixed support at each base. The template also made, for you:

    • a load case SW, the self-weight (self-weight factor 1.0), and a Linear analysis case with the same name that applies it;
    • two combinations, ULS-1.35G and SLS-G, of the self-weight alone.

    2. Look around¶

    The panel at the left opens on AI. Press Tables, then the Geometry tab: the four nodes (N0_0, N1_0 at the bases, N0_1, N1_1 at the top), and under Bars the two columns (C0_0, C1_0) and the beam (B0_1). Click a bar on the canvas to select it (the status bar counts what is selected), and double-click it to open its editor. The mouse wheel zooms, and the Pan button, or the middle button, moves the view.

    3. Add a live load case¶

    A load belongs to a load case, and a load case is only a definition: it is solved by an analysis case (see Analysis). The self-weight has its own. Add one for the live load:

    1. Loads ▸ Load Cases… opens the table of load cases. Press Add.
    2. Name Q, Action type Q – Live, Self-weight factor 0. Press OK.

    The load case Q appears, and so does a Linear analysis case Q: adding a load case always creates the matching analysis case.

    4. Load the beam¶

    Loads ▸ Distributed loads ▸ Add…, and fill in:

    Field Value
    Element B0_1 (the beam)
    Load case Q
    Fy transverse start / end (kN/m) -20 and -20 (negative is downward)
    Coord system global

    Press OK. Switch the View selector (second row, top left) to Loads, and pick the case Q: you should see 20 kN/m of downward arrows on the beam.

    5. Make the combination¶

    The design needs a combination of the cases. Analysis ▸ Auto Comb. (EN1990)… (Ctrl+Shift+C) makes them from the action type of each case, which is why Q had to be Live. The dialog shows the EN 1990 factors of each analysis case: leave them, keep ULS ticked, and press OK.

    You should see a new combination, ULS: +1.35_SW+1.50_Q, in Tables ▸ Loads ▸ Cases ▸ Combinations: 1.35 times the self-weight plus 1.5 times the live load.

    6. Run the analysis¶

    Press F5 (or Run analysis in the tool bar). You should see the Case selector appear beside View, and the padlock close: with results, the model is locked, so that it cannot change under its own results. Unlock with Ctrl+L to edit again; that discards the results.

    7. Read the results¶

    Set View to Reactions (Ctrl+5) and the case to Q. A check you can do by hand: the live load is 20 × 6 = 120 kN, so each base takes half, 60.00 kN vertically. The horizontal reactions are equal and opposite, about 11.65 kN, and each base takes a moment of about 15.50 kNm.

    Now set the case to ULS: +1.35_SW+1.50_Q and View to Force diagrams (Ctrl+6), with Diagram set to Bending moment. You should read:

    Where Bending moment
    middle of the beam about 103.25 kNm (sagging)
    top of each column, at the beam ends about 54.53 kNm (hogging)
    base of each column about 27.18 kNm

    The vertical reaction under the ULS combination is 125.44 kN per base: 1.35 × 26.25 + 1.5 × 60.00, the self-weight of 26.25 kN (half of the 52.5 kN of the frame) and the live load of 60 kN, each with its factor.

    Other things to try: Deformed shape (Ctrl+4), Shear and Axial in the Diagram selector, and View ▸ Results (F8), which has the full numeric report. What each view shows is on Results.

    8. Design it¶

    Design ▸ Concrete members (ULS) designs the beam and the columns in reinforced concrete (EN 1992-1-1) for the ULS combinations (Design ▸ Design combinations says which: by default, those whose name starts with ULS). Then open View ▸ Results ▸ Design ▸ Concrete ▸ Reinforcement: for each member, at each critical section, the required steel As,bot, As,top and the stirrups Asw/s, with ★ on the governing section. The Reinforcement (As) view draws them on the canvas. See Design.

    9. Save and export¶

    • File ▸ Save (Ctrl+S) writes a .x2d file: the model, its results, the design and the view.
    • File ▸ Results Report… (Ctrl+Shift+W) makes a PDF, Word or Excel report; Tables to Excel… (Ctrl+Shift+T) is the one-click spreadsheet.

    See Exporting and File Formats.

    Where next¶

    • Understand the model: Domains, then Modelling the Structure, and Plane models or Plate models.
    • Do it faster: the Assistant builds and edits the model from a sentence (add a 20 kN load at midspan), and the Agent does a job of several steps on its own.
    • Do it in code: Scripting with the engine builds this same frame in ten lines of Python.
