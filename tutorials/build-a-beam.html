    Create a beam or a bar from scratch¶

    The order that always works: a section, the nodes, the bar that joins them, the supports. Keep what each create_* call returns and pass that on; do not look nodes up afterwards.

    A bar of a given length (a 7 m beam)¶

    sec = model.create_rc_section('S1', b=0.3, h=0.5)    # section (it makes its material)
n1 = model.create_node(0.0, 0.0)                      # a node is (x, y) in metres
n2 = model.create_node(7.0, 0.0)                      # 7 m to the right
bar = model.create_bar_element(sec, n1, n2)           # section first, then the two nodes
model.pin(n1)                                         # supports: see the Supports tutorial
model.roller(n2, free='x')

    The ids are automatic (N1, N2, B1). Every call that takes a node, a bar, a section or a load case accepts either the object or its id as text: model.pin(n1) and model.pin('N1') are the same.

    • In the same reply, use the objects the create_* calls returned (n1, n2, bar).
    • In a later reply those variables no longer exist: refer to what is in the model by its id as text ('N1', 'B1'). The ids are in the note about the previous reply, or read them with the geometry tool.

    Do not index the model's dictionaries with numbers¶

    model.nodes and model.bar_elements_by_id are dictionaries keyed by the id as text, not lists. model.nodes[0] is a KeyError.

    # wrong: model.create_bar_element('S1', model.nodes[0], model.nodes[1])
# right: use the objects create_node returned, or the ids as text
bar = model.create_bar_element('S1', 'N1', 'N2')

    The section must exist before the bar¶

    create_bar_element('Sec', ...) with no section called Sec leaves the bar without a section. Create it first (create_rc_section, create_steel_section), or read the names that exist with the geometry tool.

    sec = model.create_steel_section('S2', 'IPE300', grade='S355')

    Several bars in a row (a continuous beam)¶

    sec = model.create_rc_section('S1', b=0.3, h=0.5)
nodes = [model.create_node(x, 0.0) for x in (0.0, 5.0, 10.0, 15.0)]
for a, b in zip(nodes, nodes[1:]):
    model.create_bar_element(sec, a, b)
model.pin(nodes[0])
model.roller(nodes[1:], free='x')

    pin, fix and roller take a node or a list of nodes.

    A column on a beam (a portal frame)¶

    sec = model.create_rc_section('S1', b=0.3, h=0.5)
a = model.create_node(0.0, 0.0)
b = model.create_node(0.0, 3.5)       # y is up
c = model.create_node(6.0, 3.5)
d = model.create_node(6.0, 0.0)
for i, j in ((a, b), (b, c), (c, d)):
    model.create_bar_element(sec, i, j)
model.fix([a, d])

    A whole standard structure in one call¶

    For a beam, frame, truss, wall or slab of a standard kind, model.create_from_template(kind, **params) builds geometry and supports together; see the Templates page. Use the calls above for anything else, or to add to what is already there.
