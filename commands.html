    Command Language¶

    The command language is a short text for building and changing a model, one command per line, without Python. The Assistant writes it when you ask it to create or change something, and an agent working through the MCP server writes it to edit your model. When the Assistant holds its commands for Apply, what you read there is this language, and this page says what each line means.

    add section S1 concrete 0.3x0.5
add node A 0 0
add node B 6 0
add bar E1 A B S1
add support pin A
add support roller B
add load 15 down on E1 case Q
set bar E1 section S2
remove load on E1

    How a line is built¶

    VERB OBJECT [ID] [SELECTOR] [properties]
    • There are a few verbs, applied to the same objects: add creates, set changes, remove deletes, move moves nodes. The same words build a model and change one that exists.
    • Units are metres, kN, kNm and degrees. x is horizontal and y is up.
    • An id is a name: you choose it when you add something, and it is the one the model shows for anything that exists.
    • # starts a comment, and blank lines are ignored.
    • add of a name that exists is an error. set and remove of one that does not exist is an error that lists the ones that do.
    • A load names its case (case Q). The case is made, as a permanent action, when it is new.

    Selectors¶

    Where a command takes an id it also takes a selector, which picks several things at once:

    Selector Picks
    N1, N1,N3 those ids
    nodes all, bars all everything of that kind
    nodes x=0.5, nodes y<2, nodes x>=3 and y=0 nodes by their coordinates
    bars section=B1, bars material=X bars by their section or material
    nodes supported, nodes free nodes with or without a support

    An empty selection is an error that says what exists (no node with x=0.5; x of the nodes: 0, 2, 4). It is never a command that quietly does nothing.

    All or nothing¶

    The commands run on a copy of the model, and the copy replaces the model only if every line worked. On an error nothing changes and the message says the line and why. This is what makes it safe to let a model, or an agent, write them: what you see before accepting is what is applied.

    Notation in the list¶

    In the list below, words in capitals are what you write (ID, SEL, X Y), [ ] is optional, | is "one of", and what follows e.g. is a line that works. The text in parentheses explains the form.

    The Assistant is taught only the forms most requests need, because a small model writes them better when it has fewer to choose from. The rest (the dynamic analyses, the Edit-menu operations and the reading commands for design, quantities and the model check) are for agents, and the interpreter accepts them all.

    The commands¶

    add¶

    Creates something new: nodes, bars, sections, supports, loads, cases, combinations, analyses, constraints. An add of a name that already exists is an error.

    add node ID X Y
    e.g. add node A 0 0
add bar ID NODE NODE SECTION [hinge-start] [hinge-end]
    e.g. add bar E1 A B S1
add section NAME concrete BxH [CLASS] | steel PROFILE [GRADE] | timber BxH [CLASS]
    e.g. add section S1 concrete 0.3x0.5
add material NAME steel GRADE | concrete CLASS [REBAR] | timber CLASS
    e.g. add material X steel S355
add slab ID X0 Y0 X1 Y1 thickness T [material M]
add slab ID thickness T [material M] points X Y X Y X Y ...
add slab ID regular sides N diameter D thickness T [material M] [center X Y]
add slab ID nodes N1 N2 [N3 ...] [section NAME]   (corners are existing nodes: 2 = rectangle, 3+ = polygon)
    e.g. add slab S1 0 0 5 4 thickness 0.2
    e.g. add slab S2 nodes A B C
add wall ID X0 Y0 X1 Y1 thickness T [material M]
    e.g. add wall W1 0 0 4 3 thickness 0.25
add support fix|pin|roller SEL [free x|y]
SEL: ids (A,D) or a condition (nodes x=0.5, nodes y=0, nodes all)
    e.g. add support fix A,D
add spring SEL [kx V] [ky V] [kt V]   (kN/m, kNm/rad; write the name of each stiffness)
    e.g. add spring B ky 2000
add spring on bars SEL [kx V] [ky V]   (a distributed spring, kN/m per metre of bar; kx axial, ky transverse to the bar)
    e.g. add spring on bars E1,E2 ky 5000
add spring on slab SEL kz V   (a Winkler spring under a slab or wall, kN/m3)
    e.g. add spring on slab Slab kz 20000
add edge REGION EDGE KIND   (EDGE 0, 1, ... or bottom|right|top|left|all; KIND pin|fix|roller-x|roller-y|symm-x|symm-y)
    e.g. add edge Slab 1 pin
add case NAME [permanent|live|wind|seismic|temperature]
    e.g. add case Q live
add selfweight CASE [factor F]
    e.g. add selfweight G
add load VALUE [down|up|left|right] on SEL [at FRACTION] [case NAME]   (kN on a node or at a point of a bar, kN/m on a bar, kN/m2 on a slab; VALUE..VALUE is a trapezoid on a bar)
    e.g. add load 15 down on E1 case Q
add load VALUE [perp|tang] on edge REGION EDGE [case NAME]   (kN/m along one edge of a slab or wall; perp is normal to the edge, tang along it; a global direction is a load on the nodes)
    e.g. add load 10 perp on edge Slab 1 case Q
add temperature uniform V [gradient V] on SEL [case NAME]
    e.g. add temperature uniform 30 on E1 case T
add settlement uy V [ux V] [tz V] on SEL [case NAME]   (uy negative is down, in metres)
    e.g. add settlement uy -0.01 on B case S
add analysis NAME = FACTOR CASE + FACTOR CASE ...   (load cases)
    e.g. add analysis ULS = 1.35 G + 1.5 Q
add analysis NAME mass = FACTOR CASE + ...   (the mass of the loads, kN / 9.81, for the modal case)
    e.g. add analysis M mass = 1 G + 0.3 Q
add analysis NAME modal mass MASSCASE [modes N]   (the vibration modes: read them with get modal)
    e.g. add analysis Modes modal mass M modes 6
add analysis NAME spectrum modal MODALCASE function SPECTRUM [direction X|Y|XY] [rule SRSS|CQC] [damping D]   (the response spectrum analysis)
    e.g. add analysis Sx spectrum modal Modes function EC8 direction X rule CQC
add analysis NAME pdelta = FACTOR CASE + ... [iterations N] [tolerance T] [beams F] [columns F]   (second order, plane domain; F is the fraction of the stiffness kept)
    e.g. add analysis P pdelta = 1.35 G + 1.5 Q beams 0.8 columns 0.8
add analysis NAME nonlinear = FACTOR CASE + ...   (unilateral springs)
add spectrum ID points T SA T SA ... [damping D]  |  add spectrum ID ec8 ag A S S TB T TC T TD T [damping PERCENT] [q Q [beta B]] [tmax T]   (the response spectrum Sa(T); ec8: the EN 1998-1 curve, ag in m/s2, elastic or, with q, design)
    e.g. add spectrum EC8 ec8 ag 1.5 S 1.2 TB 0.15 TC 0.5 TD 2
add mass SEL [mx V] [my V] [mtz V] case MASSCASE   (a concentrated mass, tonnes and t m2, for a Mass case)
    e.g. add analysis M mass = 1 G
    e.g. add mass B mx 2 my 2 case M
add combination NAME = FACTOR CASE + FACTOR CASE ...   (load or analysis cases)
    e.g. add combination C1 = 1.35 G + 1.5 Q
add combination NAME = FACTOR CASE + ... type sum|envelope|abssum|srss   (envelope: the largest and the smallest of each result over the terms; sum is the default)
    e.g. add combination ENV = 1 ULS1 + 1 ULS2 type envelope
add constraint equal SEL COMPONENTS   (the nodes move together in these components: ux uy tz)
add constraint rigid MASTER SLAVES   (the slaves follow the master as one rigid body; the master is a node, the slaves are nodes or a condition)
add constraint equation 1*A.ux -1*B.ux = 0   (the raw form)
    e.g. add constraint equal B,C ux
    e.g. add constraint rigid A B,C

    set¶

    Changes something that exists. Several attribute value pairs can go in one line.

    set slab ID mesh S | thickness T | material M   (several pairs in one line; mesh is the size of the elements)
    e.g. set slab Slab mesh 0.25
set wall ID mesh S | thickness T | material M
    e.g. set wall W1 thickness 0.3
set bar SEL section NAME | hinge-start on|off | hinge-end on|off   (several pairs in one line)
    e.g. set bar E1 section S2
set load VALUE [down|up|left|right] on SEL [at FRACTION] [case NAME]   (the load there BECOMES this value: for 'change the load to 20'; add load adds another)
    e.g. set load 20 down on E1 case Q
set section NAME ATTR VALUE [ATTR VALUE ...]   (ATTR: name, material, size BxH, b, h, thickness, cover, is_column ... any attribute of the section)
    e.g. set section S1 size 0.3x0.6
set material NAME ATTR VALUE [ATTR VALUE ...]   (ATTR: name, young 33GPa, poisson, weight, density, type ...)
    e.g. set material X young 33GPa poisson 0.2

    remove¶

    Deletes. An id that does not exist is an error that lists the ones that do.

    remove node SEL
    e.g. remove node C
remove bar SEL
    e.g. remove bar E2
remove slab ID
    e.g. remove slab S1
remove wall ID
    e.g. remove wall W1
remove section NAME
    e.g. remove section S2
remove material NAME
    e.g. remove material X
remove support SEL
    e.g. remove support nodes y=0
remove edge REGION EDGE
    e.g. remove edge Slab 1
remove load on SEL [case NAME]
    e.g. remove load on E1 case Q
remove temperature on SEL [case NAME]
    e.g. remove temperature on E1
remove spring SEL
    e.g. remove spring B
remove case NAME
    e.g. remove case Q
remove spectrum ID
    e.g. add spectrum SP points 0 1 1 2
    e.g. remove spectrum SP
remove mass SEL [case MASSCASE]
    e.g. add analysis M mass = 1 G
    e.g. add mass B mx 2 case M
    e.g. remove mass B
remove analysis NAME
    e.g. remove analysis ULS
remove combination NAME
    e.g. remove combination C1
remove constraint ID
    e.g. remove constraint C1

    move¶

    Moves nodes, to a position or by an amount.

    move node SEL by DX DY | to X Y
    e.g. move node C by 0 0.5

    select and deselect¶

    Mark nodes and bars in the window, as the Selection menu does. They change nothing in the model.

    select nodes SEL   (marks them in the window: ids with commas, all, or a condition: select nodes x>=6)
    e.g. select nodes x>=6
select bars SEL   (marks them in the window; 'select bars y=9' is the beams at y=9, both ends)
    e.g. select bars y=9
select only nodes|bars SEL   (replaces the selection with these)
    e.g. select only bars E1
select none   (clears the selection)
    e.g. select none
select previous   (the selection before this one, as Selection > Previous selection)
    e.g. select previous
deselect nodes SEL   (takes them out of the selection)
    e.g. deselect nodes A
deselect bars SEL
    e.g. deselect bars E1
deselect all   (clears the selection)
    e.g. deselect all

    divide¶

    Divides bars, triangles and quads into pieces, as the window action does. The divided id disappears: E1 becomes E1/1, E1/2, ..., so a later line cannot use it.

    divide bar SEL N | size L
    e.g. divide bar E1 3
divide triangle IDS N
    e.g. divide triangle T1 2
divide quad IDS N
    e.g. divide quad Q1 2
divide element IDS N
    e.g. divide element E1 3

    copy, array, rotate, scale, mirror¶

    The Edit menu as commands. A bar stands for its two nodes, a slab or wall for the nodes that define it. The copies get ids _c2, _c3, ..., and the answer lists them.

    copy nodes SEL by DX DY [loads]   (also on bar, slab and wall: copy bar E1 ...; the bars, slabs and walls made of the nodes come too; with loads: their loads too)
    e.g. copy nodes A,B by 6 0
array nodes SEL rect NX DX NY DY [loads]  |  array nodes SEL circular CX CY COUNT STEP [loads]   (NX by NY copies DX, DY apart, the original being the first; COUNT copies STEP degrees apart)
    e.g. array nodes all rect 3 6 1 0
rotate nodes SEL about X Y by DEGREES [cw]   (counter-clockwise unless cw)
    e.g. rotate nodes all about 0 0 by 90
scale nodes SEL about X Y by SX [SY]
    e.g. scale nodes all about 0 0 by 2
mirror nodes SEL about X Y angle DEGREES [copy] [loads]  |  mirror nodes SEL about x=V|y=V [copy] [loads]   (the line through that point at that angle from x; without copy the nodes move)
    e.g. mirror nodes all about x=6 copy

    get¶

    Reads results and facts about the model. It changes nothing; the answer is a typed value, not text to be read again.

    get value QUANTITY on ID [at x=METRES | at FRACTION] [case NAME]   (one node or bar; a bar quantity needs 'at': x=2 is 2 m from the first node, 0.5 is mid-span)
    e.g. get value M on E1 at x=2 case ULS
get max QUANTITY [on SEL] [case NAME]   (the largest value and where it is)
    e.g. get max M on bars all
get min QUANTITY [on SEL] [case NAME]
    e.g. get min uy on nodes all
get absmax QUANTITY [on SEL] [case NAME]   (the largest in absolute value, with its sign)
    e.g. get absmax V on bars all
get sum QUANTITY on SEL [case NAME]   (added over nodes)
    e.g. get sum reaction fy on nodes all case Q
get diff QUANTITY NODE NODE [case NAME]   (the first minus the second)
    e.g. get diff uy B C case Q
get list QUANTITY [on SEL] [case NAME]   (at most 10 rows)
    e.g. get list reaction fy case Q
get design steel   or   timber   or   concrete columns   or   concrete bars longitudinal   or   concrete bars shear   or   concrete bars cracking   or   concrete areas x   or   concrete areas y   or   concrete areas punching   [top|bottom] [on IDS] [worst N]   (the design results already computed, worst first; it reads, it does not design. The material of the question decides: steel or timber members; concrete columns is the utilisation of the reinforced concrete columns (1.0 is the limit), with their bars and M_Rd; concrete bars longitudinal is the As of the beams and columns (top or bottom face), shear the stirrups Asw/s, cracking the crack width; concrete areas (or shells, or panels) x or y is the As of slabs and walls in that direction (top or bottom face of a slab; a wall has none), punching the punching shear. get design alone is the summary)
    e.g. get design concrete columns
    e.g. get design concrete bars longitudinal bottom worst 3
    e.g. get design concrete areas x bottom worst 1
    e.g. get design steel worst 5
get quantities   (bill of materials: element counts, lengths, areas, volume, weight and mass by material and section)
    e.g. get quantities
get topology [free_node|coincident_nodes|tee_junction|duplicate_bar|crossing]   (the model check: topology only)
    e.g. get topology
get info ID   (everything about one node, bar, section or material: where, the bars of a node; the ends, length, angle, section, hinges of a bar)
    e.g. get info E1
get modal [case NAME] [modes N]   (periods, frequencies and participating mass of a Modal case)
    e.g. get modal modes 5
get spectrum [ID] [case NAME]   (the response spectra defined in the model: points, period range, PEAK Sa, damping; with a Spectrum case, the Sa each mode picks up)
    e.g. get spectrum
get fields [NAME] [on NODES | at X Y]   (the fields defined; one of them at the nodes where it is largest, at some nodes, or at a point)
    e.g. get fields Wind at 10 6
get count nodes|bars [CONDITION]   (how many, and which: it names them; for 'the nodes with x>=7' or 'the beams at y=9': get count bars y=9; 'the nodes with no support' is get count nodes free)
    e.g. get count nodes y=0
get supports [fixed|pinned|roller]   (how many supports, and of which kinds; with a kind, how many of that kind, none included)
    e.g. get supports
get mesh triangles|quads   (how many of them in the analysed mesh)
    e.g. get mesh triangles
get distance NODE NODE   (metres)
    e.g. get distance A B
get load [fx|fy] on NODE|BAR case NAME   (a load that was applied, not a result)
    e.g. get load fy on N1 case G
get spring on NODE case NAME   (the force in a spring)
    e.g. get spring on B case LC
get coefsum   (the load combination with the largest sum of coefficients)
    e.g. get coefsum

    Where it is used¶

    • Assistant: it writes the commands from your request, checks them on a copy, and applies them at once or holds them for Apply (see Creating and changing a model).
    • MCP server: the tools commands and check run them, grammar and reference give an agent the language, and get takes the same questions as the get commands (see MCP server).
    • Python: the same operations are in the engine, with names and arguments instead of text.
