    Loads¶

    All loads belong to a load case. A load case is purely a definition of loads — it does not produce results on its own; an analysis case solves it.

    Load cases¶

    Create load cases on the Loads tab. A load case has:

    • a name,
    • a self-weight multiplier (e.g. 1.0 to include full self-weight, 0.0 to exclude it), and
    • an action type (G permanent, Q live, W wind, E seismic, T temperature) used by the automatic Eurocode combination generator.

    Note

    Adding a load case automatically creates a matching Linear analysis case of the same name (factor 1.0), so the load case can be solved and combined right away.

    Load types¶

    The same load types exist in both domains, read in the domain's own terms: the three components of a node are Fx, Fy, Mz in a plane model and Fz, Mx, My in a plate model. The dialogs show the names of the active domain.

    Load Applies to Plane Plate
    Point load a node Fx, Fy, Mz Fz, Mx, My
    Distributed load an element trapezoidal Fy / Fx, start→end, global or local axes transverse intensity qz on a grid member
    Element point load a point along an element, at distance a Fx, Fy, Mz a transverse force and a concentrated bending moment
    Edge load a triangle or quad edge, or a surface boundary side traction Fx, Fy per unit length not used: a slab is loaded by area pressure
    Area pressure a slab region (a surface object, or a single triangle or quad) not used: a wall takes edge loads pz [kN/m²]
    Temperature (bars) an element uniform ΔT and gradient ΔT the same two values
    Temperature (areas) a triangle, a quad or a surface uniform ΔT over the element a through-thickness gradient ΔT = T_top − T_bottom
    Support settlement a supported node prescribed ux, uy, θz prescribed w, θx, θy
    Nodal mass a node (for a Mass case) Mx, My (masses on ux, uy), Mtz (rotational inertia) Mx (the mass on w), My, Mtz (rotational inertias about x and y)

    Add each from its sub-table on the Loads tab, or from the Loads menu (Manage… / Add… per type), selecting the load case it belongs to.

    Surface loads¶

    Edge loads (plane) are the surface-element counterpart of a distributed load: pick the two end nodes of a triangle or quad edge or a surface boundary side — the Add edge load tool lets you click them on the canvas — and give the traction per unit length. They are the way to apply pressure to a wall.

    Area pressure (plate) pz [kN/m²] on a slab region is the everyday slab load, drawn as a colour map over the region. Add it from Loads → Area Pressure (Manage… / Add…). A constant pressure is lumped as pz·A/3 to each vertex of a triangle and pz·A/4 to each vertex of a quad.

    Area temperature. In a plane model a uniform ΔT over a triangle or quad is a strain that stresses the element if it is restrained. A slab does not stretch, it bends, so there a triangle or surface temperature is the through-thickness gradient, which curves the plate element (a uniform rise is stress-free).

    Field temperatures need the mesh

    A field-driven temperature on a surface object only resolves once the object is meshed into triangles or quads. Before that the loads view shows a note asking you to Generate mesh (F6); a constant pressure or gradient draws immediately.

    The Winkler area spring kz of a slab on grade is applied over a region in the same way as an area pressure, but it is a support, not a load: see Plate models.

    Self-weight¶

    Self-weight is applied per load case through its self-weight multiplier, using each element's section area and material unit weight. There is no separate self-weight load to add — set the multiplier on the load case.

    Viewing loads¶

    Switch the View dropdown to Loads and pick a load case (or all load cases) to draw arrows and value labels on the canvas.
