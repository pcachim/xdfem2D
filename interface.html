    The Interface¶

    The main window has three regions: a menu bar and tool bar across the top, the left tabs for model input and results, and the canvas on the right.

    Tool bar¶

    The tool bar groups appear in a fixed order. The first three are always visible:

    Group Contents
    File New, Open, Save, Run analysis, Lock/Unlock
    Zoom Zoom window, zoom in, zoom out, fit
    View / Case View-mode dropdown, Case dropdown, mode/scale controls

    The remaining groups — Scene, Add, Edit/Delete, Transform and History — can be shown or hidden from View → Tool bar: … or in Preferences.

    History and snapshots¶

    The History group has Undo and Redo, and two snapshot buttons:

    • Save snapshot asks for a name and stores the model (without results) with the date and time.
    • Manage snapshots lists them, with Restore, Rename… and Delete (double-click restores).

    A snapshot never changes: to keep later edits, save another one. Restoring asks first, discards the results and can be undone with Undo. Snapshots are saved in the .x2d file and come back when it is opened (.json files do not keep them), and creating, renaming or deleting one marks the model as modified. New, Open, Import and New from Template start with the snapshots of the file, or none.

    Menus¶

    • File — New, New from Template, Open (+ Recent), Import… (SAP2000 .s2k, DXF), Save / Save As, Export… (SAP2000 .s2k, DXF, Robot .str, Python script), Write Report… (Word), Write Tables to Excel…, Print Graphics…, Preferences, Exit.
    • Edit — Undo/Redo, Cut/Copy/Paste, Delete, transforms (Move, Array, Rotate, Scale, Mirror), Curve to bar / Area to triangle (bake a geometry object into real elements), Select All, Find Entity.
    • Structure — Project Info; Materials, Sections (Bar / Area), Spectral Functions, Fields; and the geometry entries: Nodes (+ Node Springs, coincident-node check/merge), Bars (+ Bar Springs), Triangles, Objects (segment, arc, multisegment, rectangle, polygon), Supports, Constraints, Model check, and Add model from file (merge a second model, welding coincident nodes).
    • Loads — submenus for Point, Distributed, Edge, Settlement and Temperature (bars / areas) loads, each with Manage… and Add…; plus Load Cases.
    • Analysis — Analysis Cases, Combinations, Auto Comb. (EN1990); Cuts (Add cut…, Manage cuts…, Results… — see Results → Cuts); Generate mesh (F6), Model info, Run (F5), Lock (Ctrl+L); plus Variants Workspace… (which includes the Sequences tab) when the variants & construction sequences feature is available.
    • Design — Code preferences, Design combinations, Buckling lengths…, then, in groups: Concrete — Concrete Members (ULS), Crack width, Suggest column reinforcement, Beam definitions, Beam bars detailing…, Concrete Areas (ULS) and Punching…; Steel — Steel Members (ULS); Timber — Timber Members (ULS) and Special timber beams. See Design.
    • Scene — switch, create, rename, delete Scenes.
    • Selection — Select all / by…, Previous, Invert, Clear, Edit selected nodes / bars / triangles, Divide bars.
    • View — View mode, panel and tool-bar visibility toggles, Theme (light, dark or follow the system — for this session only, see Preferences), and Navigate to… (Alt+1 … Alt+7) for the input panels that the canvas and Find Entity do not already reach: supports, springs, materials, sections, loads, combinations, analysis cases.
    • Help — Documentation (F1), Keyboard Shortcuts, About.

    Left tabs¶

    • Geometry — Nodes, Elements, Supports, Springs, Constraints.
    • Properties — Materials, Sections.
    • Loads — Loads, Analysis Cases, Combinations.
    • Analysis — Results, Design.

    Hide or show the whole panel with View → Tables panel (F9).

    The left dock also hosts on-demand workbench tabs that open beside Tables / Assistant:

    • Punching — the column list and its actions (plate models). See Design.
    • Buckling — opened by Design → Buckling lengths…, a read-only table of the selected members where you assign the per-member buckling-length factors K. It closes with its own OK button. See Design → Buckling lengths.
    • Cuts — opened by Analysis → Cuts → Results…: cut and case selectors, the Bars/Areas/Total resultant table, and the distribution plot with CSV export. See Results → Cuts.

    Preferences¶

    File → Preferences is organised in tabs: General, Display, Design, Colors, AI Assistant and Dependencies.

    The General tab holds the theme, the default file location, the coincident-node tolerance, the default grid spacing and snap, and whether to open the last model at startup. View options says what is shown when the application starts: the Panels (Tables, Assistant, Display) and the Tool bars (Add, Edit / Delete, Transform, Scene, Variants, Sequences). It also lists the last used model and the recent models, with buttons to clear the list or drop the files that no longer exist.

    The Display tab holds the display sizing defaults (text, marker and line sizes) and the persistent style defaults — the colour map for each field, the default number of levels, continuous vs. banded fill, smoothing, and the bar-diagram and utilisation-ratio styling. The Design tab holds the default design code per material (concrete, steel, timber), whose options come from the same registry as Design → Code preferences; a code stored inside an opened .x2d takes precedence over this default.

    Preferences, this session, and what the application remembers¶

    Three different things are kept apart:

    • Preferences (~/.xdfem2d/preferences.json) are what a launch starts with. They change only in the Preferences dialog: OK saves them, Cancel changes nothing. The one other way is the explicit Set as default of the Style tab.
    • This session. Whatever you change while the application runs — View ▸ Theme, the panel and tool-bar toggles of the View menu, the assistant's temperature, Think, Task and model in its panel, the tolerance asked for when you merge coincident nodes — lasts until you close the application and is not saved. When you change the same setting in the Preferences dialog and press OK, that choice replaces the session's; the settings you did not touch keep the value you chose in the session. To make a toggle permanent, set it in Preferences.
    • What the application remembers (~/.xdfem2d/state.json) is not a choice of yours: the recent files and the last folder, the acceptance of the liability notice, the licence cache, the first-run check for the optional tools, and the assistant warnings you switched off with Don't show this again (Preferences ▸ AI Assistant ▸ Show the assistant's warnings again brings them back). The application writes it when it needs to.

    Older versions kept all of this in preferences.json; the first launch of a newer one moves the remembered part to state.json and leaves the preferences alone.

    Display panel¶

    A dockable Display panel (toggle with View → Display panel) has two tabs.

    Model — what is drawn in the scene, in one row per kind of entity: Nodes (markers, labels), Bars (shown, labels), Areas (shown, labels, borders), Objects (shown, labels), Supports (markers, constraints), Springs (nodes, elements) and Cuts; hover a box for its full name. The title of a row is faded only when the model has nothing of that kind. In the deformed and modal views an Undeformed structure toggle draws the reference geometry behind the deformed shape. When the model has geometry objects, the Structure view gains a Mesh checkbox that overlays the finite-element mesh generated from those objects (visual only — picking stays on the objects). Below the layers:

    • Colour by — Model (one colour), Sections or Materials. Bars, areas (triangles and quads) and geometry objects take the colour of their section or material — the surface of a rectangle or polygon object is filled like an area element (and its mesh, when shown, lies over that fill), not only outlined; where a result field colours the areas (stresses, shell reinforcement), the field wins. A colour stays with its section for as long as the section is in the model, so adding or removing another one does not change it; with more than 15 in use the colours repeat. The key is drawn on the canvas, lower right (the support key is upper right), so it is part of any image exported from it, and the Legend checkbox hides it; past 12 entries it says +N more. The list under the box shows every section or material in use — a section with its size (S1 · 0.30×0.50, a catalogue profile, or t=0.20 for an area) — with how many items use it; click an entry to select them on the canvas (Ctrl or Shift for several).
    • Grid — a section that opens and closes: gridlines, spacing, minor (snap) spacing, snap to grid, and the reference lines with their snap.
    • Legend and Reset display, which turns the layers back to their defaults.

    Style — live, session-only styling of the active view, in two sections:

    • Colour maps — the colour map of the active view's field. Stresses/forces, shell reinforcement, plate displacements, scalar fields and pressure / temperature loads each keep their own colour map, chosen from one curated, science-friendly list (perceptually-uniform, diverging and sequential palettes, each shown with a preview swatch; no rainbow maps). Also here: continuous vs. discrete (banded) fill, number of levels, contour lines, nodal smoothing, and a manual colour-scale range. The section is enabled only in views that actually draw a colour-mapped field.
    • Diagrams — styling for the bar views. For force diagrams (M/V/N): positive / negative colours, fill opacity, line width, filled band vs. outline, and value labels. For utilisation-ratio colouring (steel / timber design): the colour scheme (traffic-light green→red, or any colour map), the pass/fail threshold, the over-limit colour and the bar width. Each sub-panel is enabled only for the view it applies to.

    At the bottom, Save style… / Load style… / Set as default export or import the whole visualization style (colour maps, diagram and ratio styling, and the colour registry) as a portable .json preset, or persist the current style as the startup default. Ready-made presets (publication, presentation, colorblind-safe, grayscale, high-contrast, blueprint) ship in the repository's styles/ folder.

    Changes made in the Style tab apply only for the current session; the persistent defaults live in Preferences ▸ Display (and Set as default writes the current style there).

    Canvas navigation¶

    Action Control
    Zoom (anchored at cursor) Mouse wheel
    Pan Hold the middle button (wheel) and drag
    Zoom to a window Zoom-window button, then drag a rectangle
    Zoom in / out / fit Tool-bar buttons, or = / - / 0
    Select Left-click an item, or drag a selection rectangle
    Cancel add mode Esc

    The selection count is shown on the right of the status bar.
