    Python API: reference¶

    Every public call of Structure2D, with its complete signature: every parameter, its type and its default. The guide pages (building a model, loads and analysis, results and design) explain how to use them; this page is the list. Under each signature is the first sentence of its docstring; help(Structure2D.name) in Python shows the rest.
