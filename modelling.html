    Modelling the Structure¶

    Build a model from the Geometry and Properties tabs, or directly on the canvas. The model must be unlocked to edit (toggle with Ctrl+L); running an analysis locks it.

    This page is what both domains share: materials, sections, nodes, the families of elements, and the editing tools. What belongs to one domain is on its own page, with the same layout: Plane models (frames and walls) and Plate models (slabs and grillages). The mechanisms that act the same way in both are on Supports, springs and constraints and Geometry objects. The domain is chosen once, in New model (see Domains).

    Materials and sections¶

    Define these first, on the Properties tab.

    • Material — elastic modulus E (kN/m²), unit weight γ (kN/m³), and thermal expansion α (1/°C).

    • Section — a cross-section linked to a material. A Shape field selects the geometry and which dimensions are needed; the area and second moment of area are derived automatically and shown as read-only labels:

      Shape Dimensions used
      Generic b × h (or a steel-profile override)
      Rectangular width b, height h
      Circular diameter d
      Rectangular hollow b × h, wall thickness t
      Circular hollow diameter d, wall thickness t
      I flange width b, total height h, flange tf, web tw
      T flange width b, total height h, flange tf, web tw

      A steel profile picked from the library still fills the area/inertia directly. The separate Type field (Concrete / Steel / Timber / Other) is for material /design classification and is independent of the shape.

    Built-in Rigid and Dummy

    Every model is seeded with two reserved entries — a material and a section — called Rigid (numerically very stiff, for near-rigid links) and Dummy (zero stiffness, for a member that must be otherwise restrained). They are opened read-only, cannot be renamed or deleted, and are shown at the bottom of the material and section lists.

    A surface section (the section of a triangle or a quad) is different: it carries a thickness, a material and a formulation, and it is described on the page of the domain, because the formulations are not the same (see below).

    Nodes¶

    A node has an (x, y) position. Add nodes from the Nodes sub-tab, the Structure menu, or with the Add node tool: enable it and click on the canvas to place nodes; press Esc to stop.

    Double-click a node on the canvas to edit its position, support, or spring.

    Elements¶

    An element's role follows from what it spans and the model's domain: a line element is a Beam in a plane model and a Grid member in a plate model; an area element — a triangle or a quad — is a Panel in a plane model and a Slab in a plate model. The tabs, menus and section dialogs use these names, so the same primitives read correctly in either domain.

    A bar element connects two nodes and references a section. Add elements from the Beams / Grid sub-tab or with the Add element tool: enable it, click the start node, then the end node.

    Each element end can carry a moment release (hinge), drawn as a small open circle near the node.

    A triangle and a quad are the same modelling role, so they share one selection, one Manage area elements… manager, one bulk/individual editor, and the same result views — pick the shape per element or per surface.

    Panel and Slab sections

    In the GUI a Panel (plane) or a Slab (plate) pairs a triangle section and a quad section under one name (one material/thickness choice), and the surface's Mesh as: Triangles / Quads selector decides which is used. Programmatically they are two sections (tri_sections / quad_sections) that may share a name.

    Editing on the canvas¶

    • Click to select; drag a rectangle for a window selection (left-to-right encloses, right-to-left crosses).
    • Selection menu / panel: Select all, Invert, Clear, Edit nodes, Edit elements, Delete.
    • Cut/Copy/Paste (Ctrl+X / Ctrl+C / Ctrl+V) duplicate a selection with an offset. Undo/Redo (Ctrl+Z / Ctrl+Y) cover all edits.

    Transforms and bulk edits¶

    The Edit menu applies geometric transforms to the current selection:

    Command Effect
    Move Translate by a vector
    Array Replicate along a grid (copies at a spacing, a count in each direction)
    Rotate Rotate about a point
    Scale Scale about a point
    Mirror Reflect across an axis

    Two commands bake parametric objects into ordinary, individually-editable elements: Line to bar (segment / arc / multisegment → bars) and Surface to mesh (rectangle / polygon → triangles and/or quads); the object is then removed. See Geometry objects.

    To change many entities at once, select them and use Selection → Edit selected nodes / bars / triangles… for a bulk editor, or Divide bars… to subdivide selected members into several elements.

    Checking and meshing the model¶

    • Structure → Model check (also in the Analysis menu) reports topology issues that are not auto-fixed: isolated nodes, coincident nodes, unconnected T-junctions and crossings, duplicate bars, masses on restrained DOFs, and the constraint checks above.
    • Analysis → Generate mesh (F6) compiles the geometry objects into the concrete mesh the solver uses, so you can inspect it before running — it is shown via the Mesh overlay checkbox on the Structure view (Display panel ▸ Model tab), which draws the generated mesh over the geometry objects.
    • Analysis → Model info shows a summary of the model's size and contents.
